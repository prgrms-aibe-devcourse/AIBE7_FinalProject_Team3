# GRAB 디자인 기준

## 방향

2026-10-13 전체 디자인 개선 요청에 따라 기존 화면의 색상·간격·이미지 비율 유지 조건을 이 기준으로 대체한다. 미니멀 편집숍의 큰 이미지와 타이포를 사용하되 GRAB의 기존 로고·라임색을 유지한다. API 계약, Mock 범위, 상태별 동작과 접근성은 변경하지 않는다.

## 공통

- 배경은 따뜻한 흰색 `#fafaf7`, 본문은 `#191b17`, 보조 글자는 `#64685e`, 경계는 `#dedfd8`, 패널은 흰색이다. 기존 CSS 변수를 사용한다.
- DM Sans·Manrope·Noto Sans KR을 유지한다. 큰 제목은 짧고 굵게, 본문은 충분한 행간을 둔다. 가격·집계 숫자는 같은 자릿수 폭으로 읽기 쉽게 표시한다.
- 페이지·섹션 제목 위 영문 보조 제목(eyebrow)은 로그인·회원가입 화면에만 둔다.
- 버튼은 기존 `primary-button`, `secondary-button`, `text-link`를 사용한다. 주요 작업은 검정, 선택·브랜드 강조는 라임이며 경고·오류에는 기존 위험 색을 유지한다.
- 토스트는 라임 배경에 검정 굵은 글자로 표시한다(GR-160). 검정 주요 버튼과 구분된다.
- 패널은 작은 모서리와 얇은 테두리로 구분한다. 불필요한 그림자·장식·애니메이션은 추가하지 않는다. 키보드 포커스·비활성·오류 표시를 보존한다.
- 예외: 모달은 열릴 때만 짧게 움직인다. PC는 가운데 다이얼로그가 200ms 동안 페이드되며 16px 위로 떠오르고, 모바일(460px 이하)은 하단 시트가 240ms 동안 아래에서 올라온다. 배경은 어둡게 깔고 `prefers-reduced-motion`이면 움직임 없이 바로 표시한다(GR-160).
- 기존 투명 배경 로고는 헤더에 사용하고, 짙은 푸터에서는 CSS 필터로 흰색으로 표시한다. 심볼은 인증·브랜드 소개, 배경 이미지는 홈 브랜드 배너에 사용한다. 원본 에셋은 수정하지 않는다.
- PC 1440×900, 모바일 390×844에서 검증한다. 상품 목록은 4/3/2열, 관리·입력 화면은 모바일에서 세로로 쌓는다. 긴 식별자와 이름은 화면 폭 안에서 줄바꿈한다.

## 화면별 적용

- 홈: 원본 비율의 브랜드 배너와 독립된 GRAB·WISH 인기 슬라이드. 소개 제목과 배너 주변의 별도 탐색 링크는 두지 않는다.
- 상품 목록: 제목과 필터의 위계를 분리하고 상품 이미지를 정사각형으로 통일한다. 필터와 URL 복원은 유지한다.
- 상품 상세: 큰 갤러리와 정돈된 구매 영역, 구분선으로 나눈 설명·배송. DETAIL 원본 비율은 유지한다.
- 인증: 짙은 소개 영역과 흰 입력 영역. 모바일에서는 소개 영역을 줄여 폼에 빠르게 접근한다.
- 마이페이지·주문·결제: 계정·상품·배송·금액·작업을 구분하고 총액과 주요 행동을 강조한다.
- 판매자·운영자: 제목, 상태 필터, 목록, 선택 상세의 위계를 구분한다. 상세 정보와 폼을 넓게 확보한다. 대시보드 전용 UI를 다른 화면에 복제하지 않는다.
- 미구현 재고·실적 페이지: 기능 구현 시 이 기준과 각 페이지 명세를 함께 따른다.

## 검증과 커밋

공통 기반은 별도 커밋으로, 페이지 변경은 해당 명세·와이어프레임·시각 기준과 함께 커밋한다. 같은 컴포넌트를 사용하는 WISH/GRAB 목록과 상품 상세 상태는 각각 같은 변경 단위다. 시각 기준은 바뀐 화면의 테스트 이름을 명시해 선택 갱신한다.
