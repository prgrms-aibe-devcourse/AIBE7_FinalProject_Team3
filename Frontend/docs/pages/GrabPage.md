# GRAB 상품 목록

- 경로: `/grab` (`HashRouter`, 실제 URL은 `/#...`)
- 구현 이슈: GR-77 · GR-55 · GR-76
- [와이어프레임](../wireframes/GrabPage.html)

## 조회 계약

`GET /api/v1/drops?status=GRAB&size=24`에 카테고리·상품명·품절·정렬·페이지 조건을 전달한다. 인기 정렬은 `soldQuantity,desc`이며 이 정렬은 구매 가능 상품만 반환한다. 다른 정렬은 기존 저장 상태 기준이다.

## 화면 구성

- PC: 짧은 제목과 필터 다음에 작은 상품 카드를 4열로 표시한다. 가격·남은 수량·판매 종료 일정과 품절 상태를 읽을 수 있게 둔다.
- 모바일: 카드 2열, 태블릿 3열이다. 필터는 줄바꿈하고 가격과 상태가 겹치지 않게 한다.

## 행동과 이동

카드 이미지·상품명·GRAB 링크는 상세로 이동한다. 카테고리·검색·품절·정렬·페이지는 URL에 보존한다. 서버가 정렬한 전체 결과를 사용하며 받은 한 페이지를 프론트에서 다시 인기순으로 정렬하지 않는다.

## 상태와 예외

로딩·빈 결과·오류를 목록에서 구분한다. 품절 카드도 기본 정렬에서는 표시될 수 있으므로 버튼과 상태를 구분한다. 인기 정렬 결과가 없으면 빈 상태를 표시한다.

## 인수 조건

24개/페이지, PC·태블릿·모바일 4·3·2열, 구매 가능 인기 정렬·기본 정렬·검색과 뒤로 가기 복원을 확인한다.

공통: 로딩·빈 결과·실패·권한 오류를 구분하고 키보드 포커스와 직접 진입·뒤로 가기를 확인한다. 기존 색상·글꼴·이미지 비율을 유지하며 PC 1440×900, 모바일 390×844에서 가로 넘침이 없어야 한다. 실제 구현과 API 갱신은 위 구현 이슈에서 수행한다.
