WISHGRAB마이페이지주문 상세판매자 신청

헤더: WISH · GRAB · SELLER(승인된 역할만) · MY. 판매자 신청은 MY에서 진입하고 신청 화면도 기본 헤더를 사용한다. 판매자 작업 공간: DASHBOARD · DROPS · ORDERS · INVENTORY · SALES, SHOP으로 복귀.

헤더 MY(GR-132): 로그인 상태에서는 원형 프로필 이미지 버튼("계정 메뉴", 없거나 로드 실패 시 닉네임 첫 글자 + 라임 원). 누르면 아래로 마이페이지 · 로그아웃 메뉴가 펼쳐지고 Esc·바깥 클릭·화면 이동으로 닫힌다. 터치 영역 44px 이상. 비로그인 "로그인"과 판매자 작업 공간 헤더는 그대로.

구성(GR-160): 계정 카드 → 주문·WISH(PC 2 : 1) → 계정 설정. 모바일은 계정 카드 → 주문 → WISH → 계정 설정 한 열. 주요 행동은 검정, 상태 강조는 라임. 공통 기준
